This project is a Next.js prototype for an AI-powered CV referral and candidate shortlisting system.

## What the prototype covers

- Job posting intake and AI requirement extraction
- Bulk CV upload and resume parsing
- Candidate scoring, ranking, and shortlisting
- Automated email and interview workflow support
- Referral management, analytics, and compliance controls

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Getting Started

First, run the development server inside the app folder:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the recruitment dashboard prototype.

Edit [src/app/page.tsx](src/app/page.tsx) to change the main experience.

The current UI is a front-end prototype. AI extraction, authentication, email sending, file storage, and scheduling integrations still need backend services.
